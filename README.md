# Python-projects

This repository contains various Python projects, showcasing different aspects of Python programming. Below is a list of projects included in this repository along with their descriptions.

## Projects

### [arithmetic-formatter](https://github.com/KamogeloMahlake/Python-projects/tree/main/arithmetic-formatter)
This project formats arithmetic problems for easy readability.

### [budget-app](https://github.com/KamogeloMahlake/Python-projects/tree/main/budget-app)
A simple budget app to track income and expenses.

### [mean-deviation-calculator](https://github.com/KamogeloMahlake/Python-projects/tree/main/mean-deviation-calculator)
Calculates mean, variance, and standard deviation for a given set of numbers. [Learn more](https://www.freecodecamp.org/learn/data-analysis-with-python/data-analysis-with-python-projects/mean-variance-standard-deviation-calculator)

### [polygon-area-calculator](https://github.com/KamogeloMahlake/Python-projects/tree/main/polygon-area-calculator)
A tool to calculate the area of various polygons.

### [probability-calculator](https://github.com/KamogeloMahlake/Python-projects/tree/main/probability-calculator)
Calculates probabilities based on given data sets.

### [time-calculator](https://github.com/KamogeloMahlake/Python-projects/tree/main/time-calculator)
A project to perform time calculations, such as adding or subtracting time durations.

### [to-do-list](https://github.com/KamogeloMahlake/Python-projects/tree/main/to-do-list)
A simple to-do list application to keep track of tasks.
